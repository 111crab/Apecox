## 项目背景

Apecox 使用 Unreal Engine 5.8，目标是用于 UE 游戏客户端求职展示的小规模多人英雄射击战斗原型，而非完整商业游戏。

当前事实：

- 玩家基线角色为 Epic Manny/Quinn 骨架体系。
- 同时考虑第一人称拥有者表现与第三人称远端表现。
- 已完成空手移动、死亡重生、武器拾取/装备和第一把自动步枪 Hitscan 的客户端预测与服务器权威验证。
- 当前已有 Epic UE 5.8 First Person 模板中的 Manny、步枪 Mesh，以及一套 Rifle Pro MoCap 第三人称步枪动作。
- 当前急需的是能提高第一把步枪和后续武器表现完整度的**美术与动画资产**，不是另一套必须整体照搬的射击游戏框架。
- 后续可能涉及步枪、狙击枪、手枪等武器，以及开火、换弹、切枪、ADS、奔跑、跳跃、蹲伏、受击、死亡和特殊英雄武器/技能。
- 用户不要求素材完美统一，可以重定向、调整 Socket、分层动画或做少量蓝图适配；但必须明确实际工作量与风险。
- 本次不以价格筛选。免费和付费都要调查，不能因为价格遗漏产品。

## 核心任务

调查 **UE/Fab 商城作者 Infima Games 当前能够查到的全部产品**，建立完整目录，然后判断其中哪些产品能补足 Apecox 的人物、武器、第一/第三人称动画和射击表现需求。

不要只搜索名称中带有 FPS、Weapon 或 Animation 的商品。必须先从作者官方商店/发布者主页建立产品全集，再逐项分类；同时识别已经下架、改名、合并进 Bundle 或由旧 Marketplace 迁移到 Fab 的产品。

## 第二部分：对射击美术资产逐项深挖

对相关性为“高”或“中”的产品，进一步核对以下内容。没有的信息写“未核实”，不要用常识补全。

### 角色与骨架

- 是第一人称手臂、第一人称全身、第三人称全身，还是同时包含。
- 使用 UE4 Mannequin、UE5 Manny/Quinn、自定义骨架或其他骨架。
- 是否提供 IK Rig、IK Retargeter、Control Rig、姿态说明或重定向文档。
- 动画是否可以脱离其演示角色和框架单独使用。

### 动画覆盖

逐项标注是否包含：

```text
Idle
Walk / Jog / Sprint（方向数量）
Jump / Fall / Land
Crouch / Prone
Equip / Unequip / Weapon Switch
Fire / Dry Fire
Reload / Tactical Reload / Empty Reload
ADS / Aim Offset
Hit React / Death
Melee
Inspect
左手 IK 或武器握持校正
```

还要核对：

- Animation Sequence、Montage、BlendSpace、Aim Offset、AnimBP 各自是否实际提供。
- 是否区分第一人称和第三人称两套动作。
- 是否按步枪、手枪、霰弹枪、狙击枪等武器家族提供差异动作。
- 是否包含 Root Motion、Anim Notify、曲线或 Motion Warping 依赖。
- 只展示效果但不随商品提供的内容，必须单独标明。

### 武器与表现

- 包含哪些武器 Mesh，Skeletal Mesh 还是 Static Mesh。
- 是否提供独立骨骼、枪口/弹匣/抛壳 Socket、可拆弹匣或可动部件。
- 是否提供枪口 VFX、曳光、Impact、弹壳、声音、镜头后坐力或武器动画。
- 第一人称和第三人称是否使用同一武器 Mesh，是否存在不同 LOD/比例版本。
- 是否容易替换成其他商城武器，还是与其框架和骨架强绑定。

### 技术与可拆用性

- 商品是主要提供素材，还是主要提供 Blueprint/C++ 框架。
- 哪些资产可直接迁移到 Apecox，哪些必须依赖 Infima 自己的系统。
- 是否能只取动画、Mesh、VFX、音频，而不采用它的输入、武器、伤害、库存或网络框架。
- 是否包含源码；若是预编译插件，记录 UE 5.8 升级风险。
- 多人联机、复制或 GAS 宣传只作为附带信息。Apecox 不会为了素材替换自身 GAS、预测和服务器权威架构。

重点回答：

5. 哪些产品和现有 Rifle Pro MoCap 大量重复。
6. 哪些产品适合未来狙击枪、手枪或英雄特殊武器。
7. 如果购买某个 Bundle，会不会重复购买其单品。

## 第四部分：推荐结论

给出四个层级：

```text
A. 当前第一把步枪表现最值得采用
B. 后续武器家族可能需要
C. 主要适合作为实现参考，不建议接入项目
D. 与当前目标无关
```

每个 A/B 级产品必须说明：

- 它具体解决哪个缺口。
- 是否能脱离原框架只使用美术资产。
- 与 Manny/现有武器的适配路线。
- 预计人工工作：直接使用、少量配置、动画重定向、AnimBP/蒙太奇改造、较重集成。
- 最重要的风险和购买前必须由用户在商品页确认的问题。

最后给出：

1. **最小采购组合**：以最少重复内容覆盖当前步枪 FP/TP 表现。
2. **扩展采购组合**：为后续手枪、狙击枪和英雄特殊武器预留。
3. **不建议购买清单**：说明不适合的原因，价格不能作为唯一理由。
4. **仍需人工确认清单**：只列真正无法从公开资料核实的事项。
